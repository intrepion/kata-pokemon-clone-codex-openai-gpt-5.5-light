# Shape Route 1 around four wild creatures

Route 1 will contain four wild Route 1 Creatures: a Leaf critter, an Ember critter, a Tide critter, and a Neutral Creature with a bug-like identity. This ensures any starter choice can find a useful preparation path for the Leaf-favoring Meadow Badge challenge.

**Consequences**

Encounter distribution should make all four Route 1 Creatures discoverable before Badge Meadow without requiring grinding.
