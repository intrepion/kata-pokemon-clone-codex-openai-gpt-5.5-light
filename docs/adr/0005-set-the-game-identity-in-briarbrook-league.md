# Set the game identity in Briarbrook League

We will build the game as Briarbrook League, an original woodland-river creature-catching challenge rather than an unnamed Pokemon-like shell. A named region gives the starter trio, first route, healing location, badge challenge, and creature roster a coherent identity while avoiding official franchise names and assets.

**Consequences**

The first playable world should include Home Town, Professor Grove, Route 1, Healing Hut, and Badge Meadow as named places in the First Badge Loop.
