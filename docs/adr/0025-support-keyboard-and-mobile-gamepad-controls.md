# Support keyboard and mobile gamepad controls

The game will support Arrow keys and WASD for movement, Space, Enter, and Z for Confirm Control, Escape and X for Cancel Control, plus on-screen D-pad and Confirm/Cancel controls on mobile. This keeps the First Badge Loop playable on desktop and touch devices without changing the interaction model.

**Consequences**

Browser smoke tests should cover both keyboard flow and the mobile control surface, not just click-driven menu interactions.
