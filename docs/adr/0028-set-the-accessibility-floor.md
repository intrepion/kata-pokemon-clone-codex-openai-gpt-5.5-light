# Set the accessibility floor

The minimum accessibility contract is keyboard-complete play, visible focus for menus, a readable Dialogue Log, no color-only type cues, a mute control, and reduced-motion respect for nonessential animation. This keeps the creature-catching loop usable without turning accessibility into a late polish scramble.

**Consequences**

Accessibility checks should be part of the browser smoke path for menus, controls, dialogue, and type information.
