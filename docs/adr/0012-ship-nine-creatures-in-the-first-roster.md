# Ship nine creatures in the first roster

The first build will include nine total creatures: Sprigget, Cindillo, Otterune, four Route 1 Creatures, and two Badge Meadow trainer creatures. This gives the Field Guide enough texture to reward exploration while keeping art, moves, type tuning, and tests bounded.

**Consequences**

Adding more creatures should wait until the nine-creature roster has a complete First Badge Loop with browser evidence.
