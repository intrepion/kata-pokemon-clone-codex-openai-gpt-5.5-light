# Build a top-down first badge loop

We will make an original 2D top-down creature-catching adventure whose first complete arc is starter selection, route exploration, wild encounters, capture, healing, party growth, a major trainer challenge, and a badge reward. This anchors the clone in the recognizable early Pokemon experience while keeping the playable scope narrow enough to verify end to end.

**Considered Options**

- A battle-first party simulator would be cheaper to build, but would miss the exploration and discovery rhythm that makes the reference recognizable.
- A modern 3D creature RPG would raise the fidelity burden before the capture and progression loop is proven.
- An endless collecting route would be playable, but would lack a clear win condition.
