# Use a legible starter type triangle

We will use Leaf, Ember, and Tide as the first type triangle, with Sprigget, Cindillo, and Otterune as the starter creatures. This keeps the tactical relationship familiar enough to understand immediately while using original terminology and creature names.

**Consequences**

Early battle depth should prioritize readable type advantage, HP, level, XP, and two moves per creature before adding status effects or deeper competitive mechanics.
